# rendered/k3s/apps

The root of the k3s app-of-apps. ArgoCD on l2 watches this directory (`main`), through the
`agent-seddon` Application that `~/nixos/desktop/l2/k3s.nix` installs, and applies every
`Application` manifest it finds here. ArgoCD reads only YAML and JSON, so this README is ignored and
the root syncs with no resources until K3 lands.

From K3 on, everything under `rendered/` is generated by `nix run .#k8s-render-manifests` and
checked for drift by the gate. Do not edit it by hand. See
[`docs/design/k8s/04-manifests-and-gitops.md`](../../../docs/design/k8s/04-manifests-and-gitops.md).
